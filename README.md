# Repositorio del Curso de Inteligencia Artificial - Sección A

Este repositorio contiene las prácticas, proyectos de laboratorio y bases de conocimientos lógicos del curso de Inteligencia Artificial, Sección A.

## Descripción
El repositorio almacena las implementaciones lógicas desarrolladas durante el curso, incluyendo la integración de Prolog con entornos de ejecución en Python mediante `pyswip`, configuraciones de API y evaluaciones genealógicas/lógicas.
